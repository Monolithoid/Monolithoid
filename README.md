# Monolithoid

**AI · Robotics · Game servers · Web & media**

**English** · [Français](README.fr.md)

Welcome to my GitHub profile! I develop projects involving artificial intelligence, robotics, and tools for hosting, automating and sharing content. My repositories range from AI-assisted comic creation and expressive NAO robot movements to co-op game server management.

### AI & creation

- **[ia-agent](https://github.com/Monolithoid/ia-agent)** — My artificial intelligence agent project, built with Python.
- **[ia-bd](https://github.com/Monolithoid/ia-bd)** — An AI stack to help me create comics, built with JavaScript.

### Robotics & expression

- **[nao-emotion-motion](https://github.com/Monolithoid/nao-emotion-motion)** — Learning expressive NAO arm and head movements from demonstrations, conditioned on emotion and intensity. Built with Python.
- **[NAO-V5-ressources](https://github.com/Monolithoid/NAO-V5-ressources)** — A fork of Aldebaran’s repository containing the NAO v5 user manual and language resources.

### Gaming & infrastructure

- **[myCoopHub](https://github.com/Monolithoid/myCoopHub)** — Manage co-op game servers on Coolify through a web interface and Discord automation. Built with JavaScript.
- **[steamcmd-servers](https://github.com/Monolithoid/steamcmd-servers)** — A foundation for dedicated servers using SteamCMD, with or without Wine. Built with Shell.

### Web & media

- **[galleryPerso](https://github.com/Monolithoid/galleryPerso)** — Bring files from a folder hosted on a VPS directly to the web. Built with PHP.
- **[streamEvent](https://github.com/Monolithoid/streamEvent)** — Stream events, including sports. Built with Python.

**Technologies used across my projects:** Python, JavaScript, PHP, Shell, Coolify, Discord, SteamCMD, Wine and NAO.
